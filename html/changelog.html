Changelog¶

v1.0.7 In Development¶

Added¶

  • validate-types runs mypy in strict mode over the whole package, including every vendored module.

  • workflow/validate_english_text.py replaces the docstring-only CJK check. It scans every text file in the repository, including tests, scripts, workflow files, docs and configuration, and rejects Chinese text in Python comments and docstrings as well as the comment syntaxes used by RST, Markdown, TOML, YAML, shell, TeX, CSS and JavaScript. Deliberate Chinese content in string literals (for example ChineseMathTex examples) remains allowed.

  • workflow/validate_naming.py and the validate-naming CI job enforce PascalCase class names without underscores and lowercase snake_case function and method names across the entire package, including vendored subpackages.

  • .. manim:: and .. nbcell:: examples declare the files they read with :files:: the names resolve inside examples/, are copied into the example’s working directory, and render as download cards (below the code for Manim, between the input and output cells for nbcell). The file contents join the media cache hash, so editing a sample re-renders its example.

  • workflow/validate_example_files.py and its validate-example-files CI job reject an example that reads a file without declaring it, builds a path instead of a bare name, or names a file missing from examples/.

  • flake8-syntax runs E9,F63,F7,F82 in CI, so syntax errors and undefined names fail the build as the contributor guide promises.

  • workflow/validate_example_spacing.py and its validate-example-spacing CI job enforce the example layout: imports stay together, exactly one blank line separates them from the scene class, class and def construct are adjacent, and blank lines inside construct are reserved for stage changes.

  • workflow/validate_example_names.py and its validate-example-names CI job reject Example/DocExample suffixes, non-PascalCase names, and a .. manim:: name that does not match the class in its block.

  • Every public class now carries a .. manim:: example, not only subclasses of Mobject. Data-only classes, enums, protocols, CLI helpers and OpenGL-only types render an API card in a Manim scene and keep their concrete usage below it; validate-doc-sections rejects any public class whose Examples section has no Manim block.

  • The Manim documentation supplement now has separate Constants and Classes index pages instead of two sibling sections in one document. Classes keeps its own _AnimationBuilder entry and hidden toctree.

Fixed¶

  • Image layers and grayscale image mobjects convert floating-point pixel arrays to uint8 before handing them to Manim, so examples built from np.zeros no longer fail under Pillow with Cannot handle this data type: (1, 1, 4), <f8. Images normalized to [0, 1] are rescaled to [0, 255] first.

  • validate-types installs the docs extra alongside all because mypy analyses the Sphinx directive helper and needs sphinx and jinja2 stubs to import it.

  • Type aliases now refer to the configuration classes directly: SurfaceConfig and GraphSurfaceConfig are defined after their classes, so their source no longer needs quoted forward references. Both render as GaussianSurface | SaddleSurface | ... with each class linked to its reference page; autoall still strips quotes from other aliases when the name resolves to a class in the alias module.

  • The Manim documentation supplement now documents the private animation builder returned by .animate under its real name, and its page title keeps the leading underscore. A short summary is installed for the class when Manim supplies no docstring, so the Classes autosummary row is no longer empty.

  • Project type aliases render by name again under postponed annotations: SurfaceConfig, GraphSurfaceConfig, GeometrySpec, ContourSpec, ColorRamp and SurfaceFunction stay aliases in parameter and return types instead of expanding to Union[...] or tuple[VGroup, bool]. The Sphinx hook now patches sphinx_autodoc_typehints._resolve.hints.type_hints — the binding the installed 3.17.5 release actually calls — and restores aliases parsed from the original annotation string, including names nested inside list[...] and unions.

  • Project aliases are also registered with Sphinx’s official autodoc_type_aliases option. autodoc_all discovers public alias assignments from the package AST and merges them on config-inited, so direct annotations such as ramp: ColorRamp and type[SurfaceConfig] render as linked alias names instead of expanded structures. Sphinx 9 replaces a typehints_formatter assigned during setup() with the configured value, so the earlier wrapper never saw parameter annotations.

  • Every vendored package that defines type aliases now has a Type Aliases section on its reference page. autoall gained a typealias classification that renders real py:type targets with the alias source from the module AST, so signatures such as ContourSpec link to the definition instead of appearing as plain text. Re-exported aliases are not duplicated.

  • Deprecation and runtime warnings no longer flood the pytest and CI logs: internal calls to the compatibility rate functions use their unwrapped implementations, Manim mobject getters use properties (width, height, points, z_index, axes, states, bonds), stroke updates use set_stroke, and zero-length bonds and pymunk constraint lines skip line updates that would divide by zero or warn.

  • Constant entries no longer render as empty blocks: re-exported constants carry a #: docstring, and autoall keeps short values as a normal = repr signature. Values longer than 1,000 characters, such as SYMBOLS_UNICODE, show = dict with 10,083 entries with a Show button; the button replaces the summary with the exact value inline in the signature. Class and type names inside every constant value, whether it is folded or shown in full, use the same cross-reference pass as signature defaults. Fully-qualified <class 'module.Class'> spellings are replaced by the linked short class name, and type[module.Class] by type[Class], so values such as SUPPORTED_FORMATS keep compact links to their parser classes.

  • Corrected the spelling of the node-state enum to NodeState.

  • validate_docstrings.py rejects a docstring that contains a backslash without the r prefix (non-raw-docstring), and every existing docstring now follows that rule.

  • Documentation examples render their real output again: the nbcell execution cache is read by the directive, the sample molecule files ship with the repository, and the chemistry examples run against them.

  • Nerd Font examples render the icon again instead of a 0F0320-style tofu box: the media-cache renderer now finds the font at <package>/nerdfont and installs it before the worker pool starts.

  • :output-language: pytb examples no longer show CI machine paths or the documentation runner’s own stack frame.

  • The InvalidRequestException example raises again: it projects a five-dimensional mesh, because four-dimensional meshes are now supported.

  • The installation page no longer tells Python 3.13+ users to install manim-mobject-svg with --ignore-requires-python. Both that plugin and manim-nerdfont-icons are vendored as package submodules and need no separate installation.

Changed¶

  • The six three-dimensional surface factories (gaussian_surface_scene and the other *_surface_scene helpers) are removed. Each surface scene is now configured directly: GaussianSurfaceScene(pace="fast") for an instance, or class Demo(GaussianSurfaceScene, pace="fast") when subclassing. The configuration dataclasses remain available for the config argument and for style.

  • Reference pages no longer contain empty Internal API sections. Public helpers that previously appeared there are documented beside their normal Classes, Functions and Constants sections; private implementation names are no longer part of the public API coverage score.

  • Type annotations keep from __future__ import annotations and spell class self-references as quoted class names ("Table", "MCAtom | list[MCAtom]"); typing.Self is no longer used. scripts/check_type_annotations.py now checks only that every parameter has an annotation, instead of rejecting quoted annotations.

  • Documentation builds now run Sphinx on GitHub: the Docs cache workflow publishes rendered examples to rtd-cache, builds the HTML and pushes it to rtd-html, and Read the Docs only copies that output. The contributor guide describes the split and the updated validation jobs.

  • The docs build no longer auto-links inline code just because its text exactly matches a project class name. Plain code spans stay plain; an explicit :class: role is required when a link is intended, so names used as ordinary prose no longer acquire unwanted links.

  • The Vendored Packages page now gives each package its own heading, followed by a linked upstream repository, sync point, status and one bullet per local patch — instead of a five-column table whose long patch column was hard to scan. The vendored-status cache parser reads the same heading-based list.

  • Reorganised the contributor guide into topic pages under docs/source/contributing/ — development, code style, documentation, testing and licensing, all written in reStructuredText. CONTRIBUTING.md is now only a pointer to the hosted guide.

  • All .. manim:: examples now follow one code-spacing convention: imports are contiguous, the scene class follows one blank line, class and def construct are adjacent, and blank lines inside construct mark stage changes instead of separating every statement.

  • Every documentation example class now has a descriptive name without an Example suffix (BooleanOperations-style), and generic names such as BasicScene, MainScene and MyQrCodeScene were replaced with names that describe the scene.

  • The SVG animations page renders its usage example with .. manim:: instead of showing it as a plain code block.

  • The chemistry reference page renders its 2-D molecule examples from the bundled sample .mol files, which are now shipped in examples/.

  • Every documentation example reads its sample files through :files: and a bare file name; the video example’s 3Blue1Brown.mp4 moved to examples/videos/ for the same reason.

  • The contributor guide now matches the jobs in validate.yml: the validation checklist covers every job, the coverage floor reads 90%, the test matrix is 3.11-3.15, and naming is documented as enforced by validate-naming while Literal sets and the nbcell rule remain review-only.

  • Documentation examples print structured parser and coordinate results with pprint, so nested dictionaries and lists wrap onto readable lines instead of one long line.

  • Module references across the changelog and reference pages now use explicit :mod: roles instead of relying on the auto-linker, so they stay linked when a module name also names a submodule.

  • Removed the 14 empty per-module extras (algorithm, arabic, circuit, compass, data_structures, economics, fontawesome, gearbox, mindmap, mobject_svg, sequence_diagram, table, tikz, weighted_line). Those modules need no third-party packages and install with the base package; all now lists only extras that actually declare dependencies, and the installation page documents the reduced set.

  • validate.yml now runs its 22 checks in five dependency-based jobs (static, package, layout, lint and audit), so one job installs the environment once for every check that needs it. workflow/run_checks.py is the local entry point, and the new validate_extras.py check rejects empty extras or an all extra that misses a module extra.

  • workflow/run_checks.py now accepts --root, --package, --package-dir, --docs and --examples, or reads the same values from [tool.manim-doc-checks] in the target pyproject.toml. A repository can therefore vendor workflow/ and scripts/ and run the checks against its own package and documentation tree without installing a separate distribution.

Mypy¶

  • The whole package, vendored modules included, now passes mypy --strict: the baseline of 3,875 errors across 198 of 295 files is down to 0 errors in 295 files. follow_imports = "silent" and the four-path files allowlist are gone; files = ["manim_extensions"] makes python -m mypy check every module, and the validate-types CI job installs the optional extras on Python 3.12 so missing packages cannot masquerade as type errors.

  • The baseline was dominated by arg-type (979), no-untyped-def (676), assignment (396), type-arg (363), union-attr (352), attr-defined (326), override (131), operator (103), no-any-return (98) and return-value (89). The largest package shares were machine_learning (764), chemistry (729), pymunk (408), mindmap (297), three_d (246), data_structures (201), automata (198) and meshes (161).

  • Every public and private callable now carries parameter and return annotations, and bare containers were replaced by their concrete forms: list/dict/tuple/Sequence/Callable gained type parameters, Cairo contexts became cairo.Context[Any], and the parsers share dict[int, dict[str, Any]] plus the ParsedData alias instead of unparameterised payloads.

  • Manim’s dynamic mobject attributes are typed at their source. Properties that Mobject used to expose through __getattr__ as MethodType are declared in the class body (subscript, node_style, center), while .animate builders are narrowed with cast(Animation, ...). Vector attributes such as Point3D, Vector3D and VectorND are no longer inferred as plain arrays.

  • Overrides now match their supertypes without changing runtime behaviour: vector parameters use the *Like aliases, move_to overrides accept aligned_edge and coor_mask, and deliberately different signatures (apply_function, add()/remove, the table and row __getitem__ overloads) carry narrow # type: ignore[override] comments with the list semantics kept intact.

  • Optional values are narrowed at the point of use instead of being forced into non-optional attributes: geometry and animation targets are declared VGroup | None/Mobject | None and checked before use, hasattr lookups are followed by cast, and constructor **kwargs dictionaries use dict[str, Any] rather than dict[str, object].

  • NumPy boundaries were made explicit. Point-like arguments are passed as np.array(...), arrays returned from Manim helpers are cast to their geometry aliases, np.ndarray index maps use dtype=object, and NumPy slices are normalised with np.asarray(..., dtype=int).

  • Dependencies without stubs are isolated: scikit-learn and manimpango imports use # type: ignore[import-untyped], the docutils Sphinx directive uses a module-level # mypy: disable-error-code pragma, and the machine-learning configuration uses a single assignment ignore rather than a package-wide suppression.

  • Vendored re-exports are explicit. Star-import packages now re-export with Name as Name, chemistry imports its 118 element symbols from element.element, and the manim_chemistry_molecule package advertises MCElement and MC_ELEMENT_DICT in __all__, so test_imports sees every advertised name.

  • The strict pass also uncovered and fixed real runtime defects: basic_mesh.add_face now returns the (face, new_edges) pair its callers unpack, bonds_fulfilled() compares against the minimum bond count instead of looking up the atom in it, MCMolecule no longer calls copy on a dict_values view, Array slices return node objects again, and manim.utils.polylabel.Polygon receives its points as separate arguments.

  • The changelog entry for validate-types in the Added section above is updated to describe the package-wide check rather than the first-party allowlist.
