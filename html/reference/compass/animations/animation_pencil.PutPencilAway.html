PutPencilAway¶

class manim_extensions.compass.animations.animation_pencil.PutPencilAway(mobject=None, *args, use_override=True, **kwargs)[source]¶

Bases: MovePencilTipTo

Put the pencil away: move the pencil to point.

Parameters:

  • pencil (Pencil) – The pencil.

  • point (Point3D | None) – The placement position.

  • **kwargs (object) – Additional keyword arguments forwarded to ApplyMethod.

Examples

Example: PutPencilAwayScene ¶

from manim import *
from manim_extensions.compass import DrawPath, Pencil, PutPencilAway

class PutPencilAwayScene(Scene):
    def construct(self):
        pencil = Pencil().to_edge(LEFT)
        line = Line(LEFT, RIGHT)
        self.play(DrawPath(pencil, line))
        self.play(PutPencilAway(pencil, 3 * DOWN))
        self.wait()
