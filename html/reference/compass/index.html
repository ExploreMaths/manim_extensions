Compass¶

Compass and drawing tools for Manim.

class manim_extensions.compass.Compass(span=1.5, head_color=WHITE, niddle_color=RED, pen_color=PURE_YELLOW, stroke_width=2, leg_length=3.1, leg_width=0.12, r=0.2, **kwargs)[source]¶

Compass mobject.

Parameters:

  • span (float) – Span of the compass legs.

  • head_color (ParsableManimColor) – Color of the compass head.

  • niddle_color (ParsableManimColor) – Color of the compass needle.

  • pen_color (ParsableManimColor) – Color of the compass pen.

  • stroke_width (float) – Stroke width of the compass lines.

  • leg_length (float) – Length of the compass legs.

  • leg_width (float) – Width of the compass legs.

  • r (float) – Radius of the compass head circle.

  • **kwargs (Any) – Forwarded to the parent VGroup.

Examples

Example: CompassScene ¶

from manim import *
from manim_extensions.compass import Compass

class CompassScene(Scene):
    def construct(self):
        narrow = Compass(span=1)
        wide = Compass(
            span=2.5, head_color=BLUE, niddle_color=GREEN, pen_color=ORANGE
        ).next_to(narrow, RIGHT, buff=1.5)
        self.add(narrow, wide)

Compass provides compass-and-straightedge construction tools for Manim. It includes Compass, Ruler and Pencil mobjects plus matching animation classes. The code is bundled inside manim_extensions as the compass subpackage.

Features¶

  • Compass mobject and compass animations: MoveNiddleTipTo, RotateCompass, SplitCompass, PutCompass, PutCompassAway, DrawArc.

  • Pencil mobject and pencil animations: MovePencilTipTo, PutPencilAway, MovePencilAlongPath, DrawPath.

  • Ruler mobject and ruler animations: PutRuler, PutRulerAway.

  • CompassScene – a convenience Scene subclass pre-equipped with a compass, ruler, and pencil.

Using CompassScene¶

For more involved constructions, inherit from CompassScene instead of Scene. It exposes ready-to-use compass, ruler and pencil attributes plus helper methods such as draw_arc and draw_line. See the demo/compass_scene_demo.py file in the upstream repository for a complete example.

Usage¶

The upstream toolkit grew out of compass-and-straightedge construction animations (for example, the construction of a regular 257-gon). The bundled compass, pencil, and ruler mobjects are paired with animation classes that move, place, and put away the tools.

Compass animations¶

MoveNiddleTipTo moves the whole compass so that its needle tip reaches a target point; RotateCompass rotates the compass about its needle tip; SplitCompass opens (or closes) the two legs symmetrically until the span equals the given distance:

Example: CompassAnimations ¶

from manim import *
from manim_extensions.compass import (
    Compass, MoveNiddleTipTo, RotateCompass, SplitCompass)

class CompassAnimations(Scene):
    def construct(self):
        compass = Compass().to_edge(LEFT)
        self.play(MoveNiddleTipTo(compass, ORIGIN))
        self.play(RotateCompass(compass, PI / 2))
        self.play(SplitCompass(compass, 2))
        self.wait()

References: MoveNiddleTipTo RotateCompass SplitCompass

PutCompass

places the needle tip and pen tip at two given positions; PutCompassAway contracts the legs to span_buff and parks the compass at a point:

self.play(PutCompass(compass, niddle_pos=LEFT, pen_pos=RIGHT))
self.play(PutCompassAway(compass, point=4 * LEFT, span_buff=0.2))

DrawArc draws an existing Arc with the compass: with the needle tip at the arc’s center and the pen tip at the arc’s start, it rotates the compass while the arc is drawn (it combines the RotateCompass animation with the arc’s Create).

self.play(DrawArc(compass, arc))

Pencil animations¶

MovePencilTipTo moves the pencil so its tip reaches a point; MovePencilAlongPath moves the pencil along a VMobject path (typically a Line in constructions); DrawPath draws the path: the pen tip starts at the path’s beginning and the pencil moves along it while the path is created (it combines the MovePencilAlongPath animation with Create). PutPencilAway parks the pencil at a point; it is equivalent to MovePencilTipTo and kept for readability in construction scenes:

Example: PencilAnimations ¶

from manim import *
from manim_extensions.compass import (
    Pencil, MovePencilTipTo, MovePencilAlongPath, DrawPath, PutPencilAway)

class PencilAnimations(Scene):
    def construct(self):
        pencil = Pencil().to_edge(LEFT)
        # a path for the pencil to trace
        path = Line(4 * LEFT, 4 * RIGHT)
        self.play(MovePencilTipTo(pencil, ORIGIN))
        self.play(MovePencilAlongPath(pencil, path))
        self.play(DrawPath(pencil, path))
        self.play(PutPencilAway(pencil, point=4 * LEFT))
        self.wait()

References: Pencil MovePencilTipTo MovePencilAlongPath DrawPath PutPencilAway

Ruler animations¶

PutRuler aligns one edge of the ruler between a start and an end point; PutRulerAway parks the ruler at a point (is_flat=True lays it out horizontally, otherwise vertically):

Example: RulerAnimations ¶

from manim import *
from manim_extensions.compass import Ruler, PutRuler, PutRulerAway

class RulerAnimations(Scene):
    def construct(self):
        ruler = Ruler().scale(0.7).to_edge(LEFT)
        self.play(PutRuler(ruler, start=LEFT, end=UR * 0.8))
        self.play(PutRulerAway(ruler, point=LEFT, is_flat=False))
        self.wait()

References: Ruler PutRuler PutRulerAway

To draw a straightedge line, place the ruler, move the pencil to the line’s

start, and draw the path, then put the tools away:

self.play(
    PutRuler(ruler, start=LEFT, end=UR),
    MovePencilTipTo(pencil, LEFT),
)
self.play(DrawPath(pencil, path))
self.play(
    PutRulerAway(ruler, point=LEFT),
    PutPencilAway(pencil, point=LEFT),
)

The upstream repository also ships a SingleRulerScene for single-ruler constructions (one ruler, one pencil, with a draw_line_with_pencil() method); see demo/ruler_scene_demo.py.
