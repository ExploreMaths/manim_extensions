element¶

Chemical element data structure.

class manim_extensions.chemistry.element.element.Element(symbol='H', name='H', atomic_number=1, mass=1.008, color='#FFFFFF')[source]¶

Chemical element data.

Parameters:

  • symbol (str) – Chemical symbol of the element.

  • name (str) – Full name of the element.

  • atomic_number (int) – Atomic number of the element.

  • mass (float) – Atomic mass of the element.

  • color (str | None) – Display color of the element. Falls back to "#ff00ff" when falsy.

Examples

Example: ElementOverview ¶

from manim import *
from manim_extensions.chemistry.element.element import Element

ElementTarget = Element

class ElementOverview(Scene):
    def construct(self):
        public = [n for n in dir(ElementTarget) if not n.startswith("_")]
        card = VGroup(
            Text('Element', font_size=36),
            Text('module: manim_extensions.chemistry.element.element', font_size=18, color=GREY),
            Text('Chemical element data', font_size=22),
            Text("API: " + ", ".join(public[:6]), font_size=18, color=BLUE),
        ).arrange(DOWN, aligned_edge=LEFT, buff=0.25)
        card.scale_to_fit_width(11.5).move_to(ORIGIN)
        frame = RoundedRectangle(
            width=12.1, height=card.height + 0.5, corner_radius=0.2, color=BLUE_D
        ).move_to(card)
        self.add(frame, card)

static from_csv_file(filename, element)[source]¶

Create an Element from a CSV file.

Parameters:

  • filename (str) – Path to the CSV file containing element data.

  • element (str | int) – Symbol or atomic number of the element to look up.

Return type:

Element

Returns:

A Element instance representing the result.

Raises:

Exception – Raised when element is neither a valid symbol nor an atomic number below 118, or when no matching element is found in the CSV file.
