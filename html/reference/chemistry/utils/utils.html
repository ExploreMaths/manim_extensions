utils¶

Utility functions for chemistry file parsing.

This module provides utility functions for parsing chemical molecule data.

manim_extensions.chemistry.utils.utils.mol_parser_string(mol_string)[source]¶

Parse a MOL-format string (list of lines) into atoms and bonds dicts.

Parameters:

mol_string (list[Any]) – Lines of a MOL file, with the first line being the molecule name.

Return type:

tuple[dict[Any, Any], dict[Any, Any]]

Returns:

(atoms, bonds) where each atom has coords and element, and each bond references its connected atoms and bond type/stereo/etc.

manim_extensions.chemistry.utils.utils.mol_parser(file)[source]¶

Read a .mol file from disk and return parsed (atoms, bonds).

Parameters:

file (str) – Path to the .mol file.

Return type:

tuple[dict[int, dict[str, Any]], dict[int, list[dict[str, Any]]]]

Returns:

The parsed atoms and bonds from the .mol file.

manim_extensions.chemistry.utils.utils.sdf_parser_string(sdf_string)[source]¶

Parse an SDF-format string into a list of (atoms, bonds) tuples.

SDF files can contain multiple molecules separated by $$$$ delimiters.

Parameters:

sdf_string (str) – Raw SDF file content as a single string.

Return type:

list[tuple[dict[int, dict[str, Any]], dict[int, list[dict[str, Any]]]]]

Returns:

List of (atoms, bonds) dicts, one per molecule.

manim_extensions.chemistry.utils.utils.sdf_parser(file)[source]¶

Read an .sdf file from disk and return a list of (atoms, bonds) tuples.

Parameters:

file (str) – Path to the .sdf file.

Return type:

list[tuple[dict[int, dict[str, Any]], dict[int, list[dict[str, Any]]]]]

Returns:

The list of parsed (atoms, bonds) pairs from the .sdf file.

manim_extensions.chemistry.utils.utils.get_element(element, language='ENG')[source]¶

Return the Element class instance for a given element symbol.

Parameters:

  • element (str) – Chemical element symbol (e.g. "H", "C", "Fe").

  • language (Literal['ENG', 'ESP']) – Language of the element name dictionary. "ENG" or "ESP".

Return type:

Element

Returns:

The Element class instance matching the symbol.

Raises:

ValueError – If language is neither "ENG" nor "ESP".

manim_extensions.chemistry.utils.utils.mol_to_graph(file, language='ENG')[source]¶

Parse a .mol file into a simple graph representation (atoms + bonds).

Unlike mol_parser(), this function stores atom positions under the "position" key and uses (atom1, atom2) tuples as bond keys, which is more convenient for graph traversal.

Parameters:

  • file (str) – Path to the .mol file.

  • language (Literal['ENG', 'ESP']) –

    Element name language.

    'ENG'

    English element names.

    'ESP'

    Spanish element names.

Return type:

tuple[dict[int, dict[str, Any]], dict[tuple[int, int], dict[str, Any]]]

Returns:

(atoms, bonds) where atoms maps index to element/position and bonds maps (from_idx, to_idx) tuples to bond data.
