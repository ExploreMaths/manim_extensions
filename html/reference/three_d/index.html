class manim_extensions.three_d.GraphSurfaceScene(config=None, **kwargs)[source]¶

Subclasses provide a style configuration and implement the hooks _geometry, _contours, _feature, and _caption_slots. manim_extensions.three_d.plan_timeline(duration, enabled)[source]¶

Distribute a duration across the enabled beats.

Parameters:

  • duration (float) – Total content budget in seconds.

  • enabled (set[str]) – Names of beats that should be scheduled.

Return type:

tuple[dict[str, float], list[str]]

Returns:

A mapping from beat name to duration, and the names of dropped beats.

Durations are scaled proportionally, clamped between each beat’s minimum and reference times the cap multiplier, and iterated until they converge. If every optional beat can be removed and the budget still does not fit, optional beats are dropped by priority. If every beat reaches its maximum before the budget is filled, the shorter result is accepted.

manim-3d supplies ready-made three-dimensional surface scenes, including Gaussian, saddle, paraboloid, ellipsoid, torus, and hyperboloid presets.

The code is bundled inside manim_extensions as the three_d subpackage.

Features¶

  • surface configuration classes such as GaussianSurface and SaddleSurface.

  • ready-to-render scene classes for each preset surface.

  • plan_timeline() beat planning.

  • camera, axes, contour, flip, and annotation choreography.

Usage¶

Create a complete Gaussian-surface scene with the fast pace:

from manim import *
