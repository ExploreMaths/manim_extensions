Usage
-----

Shared colour schemes and mobjects used by the machine-learning packages.

.. code-block:: python

   from manim_extensions.machine_learning.utils import colorschemes, mobjects

   scheme = colorschemes.light_mode
   connections = mobjects.NetworkConnection
