Contributing
============

Thank you for your interest in contributing to **Manim Extensions**! Contributions
are welcome — please open issues or pull requests on the
`GitHub repository <https://github.com/ExploreMaths/manim_extensions>`_.

There are many ways to help:

* **Code** — new mobjects, animations, geometry and utility helpers, or fixes
  in the vendored packages.
* **Documentation** — reference pages, tutorials, and the wording of docstrings.
* **Examples** — interactive ``.. nbcell::`` cells and rendered ``.. manim::``
  scenes.
* **Testing** — regression tests for bugs, and coverage for vendored code.
* **Bug reports** — a minimal reproduction, the expected behaviour, and the
  packages' versions.

The pages below are the review checklist for this repository. Every convention
listed there is checked by an automated script in CI, so running the same
commands locally is the quickest route to a green pull request. Please also read
the :doc:`code_of_conduct`.

.. important::

   A pull request does not need to be complete before it is reviewed: mark it
   as a draft, push what you have, and start the discussion from there.
