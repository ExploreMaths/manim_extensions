colorschemes
============

.. automodule:: manim_extensions.machine_learning.utils.colorschemes

Usage
-----

Use the shared light or dark palettes instead of hard-coding colours.

.. code-block:: python

   from manim_extensions.machine_learning.utils.colorschemes import light_mode, dark_mode

   background = light_mode.background_color
   primary = dark_mode.primary_color
