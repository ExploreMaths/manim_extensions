Classes
=======

The three style namespaces — :class:`~manim_extensions.fontawesome.manim_fontawesome.Solid`,
:class:`~manim_extensions.fontawesome.manim_fontawesome.Regular`, and
:class:`~manim_extensions.fontawesome.manim_fontawesome.Brand` — are classes whose
instances are exported as the ``solid``, ``regular``, and ``brand`` accessors.
The classes are written out explicitly below (rather than via ``autoall``)
because they are implementation details not listed in the package's
``__all__``.
