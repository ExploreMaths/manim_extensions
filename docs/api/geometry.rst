Geometry
========

.. module:: manim_extensions.geometry

This module contains pure geometric calculation functions that operate on
Manim primitives (:class:`~manim.mobject.geometry.Circle`, :class:`~manim.mobject.geometry.Line`,
:class:`~manim.mobject.geometry.Arc`) without creating any on-screen mobjects.  They are useful
for analytic geometry tasks inside a :class:`~manim.scene.scene.Scene`.
