Plugins
=======

``manim_extensions`` is itself a plugin-style extension package for Manim. It
exposes additional mobjects, geometric helpers, and animations that integrate
with the standard Manim workflow.

The following third-party plugins are also documented here. They are included
as Git submodules under ``third_party/`` and retain their original authors and
licenses.
